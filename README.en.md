# 🧰 Arck Skills

Arck's collection of reusable AI Skills. Each Skill lives in its own directory at the repository root and can be installed independently.

## Skills

| Skill | Description |
| --- | --- |
| [fuxi-prototype](./fuxi-prototype) | Create, modify, validate, package, and deliver Fuxi prototypes |

Install the Skill by giving your AI tool this directory URL:

```text
https://github.com/Dylan5237/arck-skills/tree/main/fuxi-prototype
```

See the [fuxi-prototype instructions](./fuxi-prototype/SKILL.md) for the complete workflow.
